04 / Interaction

Clicks need
a client component.

"use client";+ useState()

7:30–11:00. Pages and layouts are Server Components by default. They can render Client Components. Put "use client" at the top of a file when it needs React state, event handlers, or browser APIs. Client Components can still be pre-rendered to HTML; the boundary says where interactivity lives.

[Sources] Next.js: Server and Client Components.
