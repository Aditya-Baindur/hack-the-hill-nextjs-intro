04 / Rendering and interaction

Server by default.
Client for clicks.

Page structure
app/page.tsx
export default function Home() {
  return <h1>Hello, Hill!</h1>;
}
State, forms, browser APIs
app/idea-board.tsx
"use client";
import { useState } from "react";
The idea board needs a client component because its form changes state.

7:30–11:00. Pages and layouts are Server Components by default. They can render Client Components. Put "use client" at the top of a file when it needs React state, event handlers, or browser APIs. Client Components can still be pre-rendered to HTML; the boundary says where interactivity lives.

[Sources] Next.js: Server and Client Components.

04 / Add interaction

State makes the form work.

At the top of idea-board.tsx
"use client";
import { useState } from "react";

const [ideas, setIdeas] =
  useState(initialIdeas);
const [title, setTitle] =
  useState("");
In the submit handler
function addIdea(event) {
  event.preventDefault();
  if (!title.trim()) return;
  setIdeas((current) => [
    ...current,
    { id: Date.now(), title: title.trim() },
  ]);
  setTitle("");
}

22:00–26:00. Replace the static component with demo/app/idea-board.tsx. Show the new directive, state, form, and handler. preventDefault stops a page reload. The data resets on refresh because it is only in React state.
